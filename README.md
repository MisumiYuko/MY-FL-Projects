# 🎹 FL Studio Projects

A public archive of **193 original FL Studio projects** (2019–2026) by **Misumi Yuko**. Each entry lists its collection, date, the tracked work-time, tempo, and the third-party plugins used.

## How to use
- **Browse / grab a project file:** the `.flp` files live under `projects/<year>/`.
- **Load with samples:** download the project's **bundle zip** (Files column) from the [Releases](../../releases) page — it contains the `.flp` plus its `Samples/` so the project opens complete in FL Studio.
  - The internal sample paths point to an old drive, so FL may prompt once; it auto-finds the samples by filename inside the bundled `Samples/` folder.
  - **Plugins** lists only third-party VSTs — FL's own stock plugins aren't listed (you already have them if you run FL Studio).
